# Images Directory

This folder contains all images used in the proposal website.

## Current Images Needed

### Profile/About Section
- **about.jpeg** - Main portrait photo for the "About Sabina" section - REQUIRED
  - Recommended size: 800x1067px (3:4 aspect ratio)
  - Format: JPG or PNG

### Gallery Section
- **smile.jpeg** - "Your beautiful smile" (3:4 aspect ratio) - REQUIRED
- Add more photos and name them: `gallery-1.jpg`, `gallery-3.jpg`, etc.
- Recommended size: 1200x1200px or similar
- Format: JPG or PNG

### Dream Destinations (Travel Section)
These images are already in place but can be replaced with your preferred photos:
- `thailand.jpg` - Thailand destination
- `bali.jpg` - Bali destination
- `south-africa.jpg` - South Africa destination
- `world.jpg` - General world travel image
- `dream-home.jpg` - Future home dreams

## How to Add Your Images

1. Simply drag and drop your images into this folder
2. Update the filenames in the respective component files if needed
3. Images will be automatically optimized by Next.js

## Tips
- Use high-quality images for best results
- Optimize large images before uploading (use tools like TinyPNG)
- Keep filenames simple and lowercase
- Recommended formats: JPG for photos, PNG for graphics
